# 시간표 -> Google 캘린더

수강신청 페이지에서 내 과목을 긁어 Google 캘린더용 `.ics` 를 만듭니다.
파이썬은 표준 라이브러리만 씁니다. 설치할 것이 없습니다.

```
수강신청 페이지 ──crawl.js(콘솔)──> timetable.json ──run_timetable.bat──> timetable_2026_fall.ics
                                                        │
                                                   courses.csv (색/강의실 보정용, 안 건드려도 됨)
```

---

## 사용법

### 1. 자료 긁기 (학기당 한 번)

1. 수강신청 페이지(`/ucr/ucreTlsnAplymMngt/index.do`)를 **로그인한 상태로** 엽니다
2. `F12` -> `Console` 에 `crawl.js` 내용을 통째로 붙여넣고 실행합니다
3. 출력된 JSON을 이 폴더에 **`timetable.json`** 으로 저장합니다
   - 자동 복사가 안 되면 콘솔에 `copy(timetable)` 을 입력하면 클립보드로 들어갑니다

긁는 것: 과목코드, 분반, 과목명, 강의시간, **강의실**, 학점, 교수, 이수구분, 학부,
그리고 개강일(수강변경기간 첫날)과 종강일.

로그인된 세션에서 사이트가 쓰는 요청을 그대로 호출합니다. 비밀번호나 쿠키를 다룰 일이 없습니다.

### 2. 만들기

```
run_timetable.bat        빠른 실행
```

또는 직접:

```
py make_timetable.py
```

배치는 년도/학기/시작일을 묻지 않고 긁어온 값을 씁니다. 직접 실행하면 물어보고,
엔터만 치면 같은 값이 들어갑니다.

```
년도 [2026]:
학기 (1/2/여름/겨울) [2]:
수업 시작일 (YYYY-MM-DD) [2026-08-24]:
  -> 2026-08-24 월요일 시작
```

시작일이 월요일이 아니어도 그대로 진행합니다. 요일만 알려주고, 주차는 그 날부터
7일씩 끊습니다.

### 3. 가져오기

Google 캘린더 -> 설정 -> 가져오기/내보내기 -> 파일 선택 -> **캘린더에 추가**에서 대상 선택

**시간표 전용 캘린더를 새로 만들어** 거기로 넣는 것을 권합니다. 학기가 끝나면
캘린더째 지우면 되고, 쓰던 캘린더와 섞이지 않습니다.

안 듣는 과목이 한두 개 섞여 있으면 **캘린더에서 그 일정만 지우는 게 가장 빠릅니다**
(일정 -> 삭제 -> "모든 일정").

## 날짜를 어떻게 정하는가

| 항목 | 근거 |
|---|---|
| 시작일 | **수강변경기간 첫날** (`수강변경기간 : 2026/08/24 (09:00) ...`) |
| 년도 | 시작일의 연도 |
| 학기 | 시작일의 달 -> 2-3월 `1`, 6-7월 `여름`, 8-9월 `2`, 12-1월 `겨울` |
| 주차수 | 종강일 - 시작일. 못 찾으면 16주 |
| 반복 종료 | 마지막 수업 주의 7일째 23:59:59 (KST) |
| 시험 주 | `--skip` 주차(기본 8, 16)를 `EXDATE` 로 빼서 그 주만 구멍을 냅니다 |

1주차는 과목마다 자기 요일 기준입니다. 시작일이 8/24(월)이면 화-목 수업의 1주차는
8/25이고, 시작일이 수요일이어도 각 요일이 처음 오는 날부터 셉니다.

## courses.csv (안 건드려도 됩니다)

실행할 때마다 갱신되는 중간 파일입니다. **손볼 일이 있을 때만** 열면 됩니다.

| 열 | 설명 |
|---|---|
| 과목코드 / 분반 / 과목명 / 시간 / 설명 | 긁어온 값. 고쳐도 다음 실행 때 덮어써집니다 |
| **장소** | 강의실. 수업계획서에 없는 과목은 비어 있으니 직접 적으면 유지됩니다 |
| **색** | `tomato` `seagreen` 등 CSS 색 이름. 비우면 자동 배정 |
| **제외** | `Y` 를 적으면 그 과목을 뺍니다 (확장용. 보통은 캘린더에서 지우는 게 빠릅니다) |

`장소`, `색`, `제외` 는 **과목코드 + 분반**으로 찾아 다음 실행에도 유지됩니다.
엑셀로 열어도 한글이 안 깨집니다 (UTF-8 BOM).

## 옵션 (평소엔 쓸 일 없음)

| 옵션 | 설명 |
|---|---|
| `--start 2026-08-24` `--year` `--term` | 감지값 대신 직접 지정 |
| `--weeks 16` `--skip 8,16` | 전체 주차와 수업 없는 주차 |
| `--only CHEM303` | 그 과목만 만듭니다. 한 과목만 다시 넣을 때 |
| `--exclude RP302` | 그 과목을 뺍니다 (CSV `제외` 칸을 안 쓰고 일회성으로) |
| `--all` | CSV `제외` 칸까지 무시하고 전부 넣습니다 |
| `--uid-suffix v2` | UID에 꼬리표를 붙여 **완전히 새 일정**으로 만듭니다 |
| `--json` `--csv` `--out` | 입출력 파일 경로 |
| `--html` `--table` | 예비 경로: 페이지 소스 HTML에서 직접 읽습니다 |

### 다시 가져올 때 주의

UID가 같으면 기존 일정이 **갱신**됩니다. 전에 개별 회차를 지웠다면 그 삭제가 남아
있을 수 있는데, 그때는 `--uid-suffix v2` 로 새 일정을 만드세요. 단, 기존 시리즈를
먼저 지워야 두 벌이 안 생깁니다.

한 과목만 다시 넣는 예:

```
py make_timetable.py --only CHEM303 --uid-suffix v2 --out chem303.ics
```

## 예비 경로: HTML에서 직접 읽기

`timetable.json` 이 없으면 수강신청 페이지 소스를 저장한 HTML을 찾아 읽습니다.
브라우저 콘솔을 못 쓰는 상황을 위한 대비책입니다.

1. F12 -> Elements -> `<html>` 우클릭 -> **Copy > Copy outerHTML**
2. 이 폴더나 `다운로드\시간표\` 에 `.html` `.htm` `.txt` 로 저장

최근 파일부터 훑어 **과목 표가 실제로 든 파일**을 고릅니다. 이 경로에는 강의실이
없습니다 (수강신청 표에 강의실 열이 비어 있기 때문). `courses.csv` 에 직접 적으면 됩니다.

## 문제가 생기면

| 증상 | 원인과 조치 |
|---|---|
| 콘솔에서 `신청내역 그리드(#grid2)를 못 찾았습니다` | 수강신청 페이지가 아닙니다. 주소를 확인하세요 |
| 콘솔에서 `강의실 조회 실패` | 로그인이 풀렸을 수 있습니다. 새로고침 후 다시 실행 |
| 자동 복사가 안 됨 | 콘솔에 `copy(timetable)` 입력. 출력을 드래그해 복사해도 됩니다 |
| `긁어온 자료도 CSV 도 없습니다` | `timetable.json` 을 이 폴더에 저장했는지 확인 |
| `--skip 은 주차 번호만 쉼표로 적는다` | `--skip 8,16` 처럼 숫자만 |
| 강의실이 비어 있음 | 그 과목은 수업계획서에 강의실이 없습니다. `courses.csv` 에 직접 적으세요 |
| 배치 창의 글자가 깨짐 | `run_timetable.bat` 은 영어만 출력합니다(ASCII). 한글은 파이썬이 콘솔에 직접 쓰므로 코드페이지와 무관하게 안 깨집니다. 그래도 깨지면 콘솔 글꼴을 굴림체 계열로 바꿔보세요 |

## 파일

| 파일 | 역할 |
|---|---|
| `crawl.js` | 브라우저 콘솔에서 실행. 과목과 강의실, 학기 날짜를 긁습니다 |
| `make_timetable.py` | 본체 |
| `run_timetable.bat` | 빠른실행용 |
| `timetable.json` | `crawl.js` 결과 |
| `courses.csv` | 중간 파일 + 색/강의실/제외를 손보는 곳 |
| `timetable_YYYY_학기.ics` | 결과물 |

`full_html.txt`, `rooms.txt`, `syllabus.txt`, `2026_Fall_Schedule.jpg` 는 예전 방식에서
쓰던 파일입니다. `full_html.txt` 만 예비 경로에서 쓰이고 나머지는 지워도 됩니다.

## 한계

- 현재 포털(jqGrid) 기준으로 만들었습니다. 페이지가 크게 개편되면 `crawl.js` 의
  열 이름(`SBJT_NO` 등)이나 조회 주소를 손봐야 합니다
- 공휴일 휴강은 반영하지 않습니다. 시험 주만 `--skip` 으로 뺍니다
- 보강/휴강 같은 개별 변경은 캘린더에서 직접 수정해야 합니다
- Google은 가져오기 때 `.ics` 의 색 지정을 무시합니다. 색은 가져온 뒤 과목마다
  한 번씩 지정해야 합니다. 알림도 캘린더 기본값이 붙을 수 있습니다
